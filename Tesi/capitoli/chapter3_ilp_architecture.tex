\chapter{System Architecture, Mathematical Formulation, and Implementation}
\label{chap:ilp_architecture}

This chapter provides a comprehensive dissertation on the theoretical framework, mathematical optimization formulation, and concrete software architecture of the proposed Centralized Integer Linear Programming (ILP) Orchestrator. 
To avoid conceptual disconnection between the theoretical modeling and its practical realization, each section progressively couples the formal system dynamics with its executable implementation in Python, utilizing the \texttt{SimPy} discrete-event simulation engine and the \texttt{PuLP} mathematical programming library backed by the \texttt{HiGHS} solver. 

We formalize the regional Low Earth Orbit (LEO) constellation environment, derive the multi-objective optimization problem governing task assignment and multi-hop Inter-Satellite Link (ISL) routing, detail the dynamic batching and greedy recovery mechanisms, and conclude with a rigorous computational complexity analysis.

\section{Regional Constellation Architecture and Offloading Model}
\label{sec:system_model}

We consider a regional orbital edge computing network deployed within a Low Earth Orbit (LEO) satellite constellation. 
The system comprises a set of candidate Satellite Edge Nodes (SENs), denoted by $S = \{1, 2, \dots, n\}$, and a set of regional Access Points (APs) or satellite gateways $AP_{global}$. 
Within the operational region, a designated \emph{Master} functions as the centralized orchestrator, maintaining global visibility over constellation kinematics, dynamic processor queue occupancies, residual battery energy budgets, and active inter-satellite link topologies.

Ground Users (GUs) generate computational requests that arrive dynamically at the regional gateways. 
Each offloading request $r \in R$ is characterized by a five-element tuple:
\begin{equation}
    r = \left( d_{cpu}, D_r, s_r, t_{arr}, AP_r \right)
\end{equation}
where $d_{cpu}$ is the computational CPU workload demand, $D_r$ represents the maximum allowable service processing deadline, $s_r$ denotes the input/output image size (in MB), $t_{arr}$ is the generation timestamp, and $AP_r \in AP_{global}$ identifies the originating entry point.

To achieve robust real-time execution in highly dynamic space environments, the operational lifecycle of task $r$ is modeled as a decoupled, three-phase circuit:
\begin{enumerate}
    \item \textbf{Uplink Control and Forwarding Phase ($T_{up}$):} The originating gateway $AP_r$ injects a lightweight control payload $S_{req} = 2~\text{KB}$ into the orbital plane, which is routed across $h_{up}(r,i)$ ISL hops to candidate satellite $i \in S$.
    \item \textbf{On-Board Computational Execution Phase ($T_{cpu}$):} Satellite $i$ processes $d_{cpu}$ units of work, incurring both the deterministic waiting time in the on-board processor queue $W_{cpu,i}$ and the physical execution delay.
    \item \textbf{Post-Execution Geographic Result Delivery ($T_{down}$):} Upon computation completion, the generated output payload is routed back from the executing satellite $i$ to the originating Access Point $AP_r$ across the dynamic ISL topology via an autonomous geographic greedy routing protocol.
\end{enumerate}

Because result return is governed dynamically in real time by the autonomous greedy protocol, the centralized ILP orchestrator focuses its optimization capacity on the joint satellite selection, uplink multi-hop routing, and processing deadline compliance.

\section{Event-Driven Dynamic Batching Engine}
\label{sec:dynamic_batching}

In a high-throughput satellite environment, invoking an NP-hard ILP solver upon each individual task arrival introduces prohibitive computational overhead and CPU starvation. 
To address this, the Master Orchestrator implements an event-driven dynamic batching mechanism inside a \texttt{SimPy} discrete-event framework, governed by two competing thresholds:
\begin{itemize}
    \item \textbf{Maximum Batch Size ($BS$):} A structural threshold (\texttt{centralized\_batch\_size}) that limits the maximum number of requests solved concurrently, bounding the solver variable space $|R| \times |S|$.
    \item \textbf{Batch Timeout ($BT$):} A temporal threshold (\texttt{centralized\_batch\_timeout}) that enforces a maximum buffering delay, ensuring requests are not stalled indefinitely.
\end{itemize}

The execution loop remains quiescent until the arrival of the first request into \texttt{task\_buffer}, which immediately succeeds \texttt{item\_arrived\_event} and initiates the timeout timer. 
The batch is dispatched when either $|Q| \ge BS$ (triggering \texttt{batch\_ready\_event}) or when the elapsed time satisfies $\Delta t \ge BT$.

A critical design requirement in discrete-event simulation is ensuring state consistency. 
Because satellite positions, CPU queue lengths, and energy levels evolve continuously, the orchestrator executes a zero-delay yield (\texttt{yield self.env.timeout(0)}) immediately prior to batch processing. 
This yields thread execution back to the \texttt{SimPy} event loop, ensuring that all physical updates across the constellation at timestamp $t$ are fully committed before optimization begins.

\begin{lstlisting}[language=Python, caption={Orchestrator Class Architecture and SimPy Event Loop.}, label={lst:orchestrator_init}]
import heapq
import simpy

class Orchestrator:
    def __init__(self, env, config):
        self.env = env
        self.config = config
        
        # Retrieve batch configuration parameters from config dictionary
        self.batch_size = config.get("centralized_batch_size", 5)
        self.batch_timeout = config.get("centralized_batch_timeout", 0.25)
        
        self.task_buffer = []
        
        # SimPy event handlers for dynamic batching triggers
        self.item_arrived_event = self.env.event()
        self.batch_ready_event = self.env.event()
        
        # Spawn the orchestrator background process in SimPy
        self.env.process(self._run_loop())

    def add_task(self, task_data, task_id, visible_aps):
        """
        Enqueue an incoming task into the buffer and handle event triggers.
        """
        if not self.task_buffer and not self.item_arrived_event.triggered:
            self.item_arrived_event.succeed()

        if "arrival_time" not in task_data:
            task_data["arrival_time"] = self.env.now

        self.task_buffer.append({
            "task_id": task_id,
            "data": task_data,
            "visible_aps": visible_aps,
            "arrival_time": self.env.now
        })

        if len(self.task_buffer) >= self.batch_size and not self.batch_ready_event.triggered:
            self.batch_ready_event.succeed()

    def _run_loop(self):
        """
        Main lifecycle of the orchestrator, managing event-driven waits without blocking the simulation environment.
        """
        while True:
            # 1. Wait idle until the arrival of the FIRST task in the buffer
            if not self.task_buffer:
                yield self.item_arrived_event

            # 2. Initialize batch timer (Timeout)
            timeout_event = self.env.timeout(self.batch_timeout)

            # 3. Wait until either batch capacity is reached OR the timer expires
            yield self.batch_ready_event | timeout_event

            # 4. Process accumulated tasks in the current batch
            if self.task_buffer:
                trigger_reason = "Maximum Capacity" if self.batch_ready_event.triggered else "Timeout"
                print(f"[{self.env.now:.3f}] Orchestrator: ILP trigger due to {trigger_reason} ({len(self.task_buffer)} tasks).")
                
                # --- SIMPY STATE SYNC: FORCE CONSTELLATION STATE UPDATE ---
                # Yield control to the event loop to ensure physical satellite state updates 
                # (CPU queues, energy levels, orbital positions) at timestamp t.
                yield self.env.timeout(0)
                # ----------------------------------------------------------

                self._process_batch()

            # 5. Reset events for the subsequent batching cycle
            self.item_arrived_event = self.env.event()
            self.batch_ready_event = self.env.event()

    def _process_batch(self):
        """
        Core routine managing constellation state extraction, ILP resolution, and task dispatching.
        """
        # A. Extract dynamic constellation network topology
        network_state = self._map_constellation()
        
        # B. Invoke the PuLP ILP solver routine
        assignments = self._solve_ilp(network_state, self.task_buffer)
        print(f"[{self.env.now:.3f}] Orchestrator: ILP execution completed.")

        # C. Execute/dispatch tasks based on optimization decision matrix
        self._dispatch_tasks(assignments)

        # Clear task buffer for the next incoming batch
        self.task_buffer.clear()

\section{Constellation Topology Mapping and Metric Normalization}
\label{sec:constellation_mapping}

Before formulating the optimization model, the Master Orchestrator must compute the optimal multi-hop ISL routing paths from every active ground Access Point to all candidate Satellite Edge Nodes. 
This is handled by the \texttt{\_map\_constellation} method using a Multi-Source Dijkstra path algorithm.

Evaluating dynamic satellite links with raw physical dimensions introduces dimensional bias (e.g., comparing milliseconds of propagation delay against microjoules of radio energy). 
To achieve uniform metric evaluation across heterogeneous links, each directed edge $(u, v)$ with latency $\tau_{u,v}$ and bandwidth $B_{u,v}$ (in Bytes/s) is evaluated against a standardized reference payload $S_{ref} = 1~\text{MB}$ ($1024^2~\text{bytes}$):
\begin{equation}
    t_{link}(u,v) = \tau_{u,v} + \frac{S_{ref}}{B_{u,v}}
\end{equation}
\begin{equation}
    e_{link}(u,v) = P_{net} \cdot \frac{S_{ref}}{B_{u,v}}
\end{equation}
where $P_{net}$ is the radio transmission power (\texttt{Ptrasm}).

The edge metrics are normalized against theoretical upper bounds ($T_{max}$ and $E_{max}$) derived from minimum network bandwidth ($B_{min} = 100~\text{KB/s}$) and maximum link latency ($\tau_{max} = 100~\text{ms}$):
\begin{equation}
    \hat{t}_{link}(u,v) = \frac{t_{link}(u,v)}{T_{max}}, \quad \hat{e}_{link}(u,v) = \frac{e_{link}(u,v)}{E_{max}}
\end{equation}
The composite dimensionless edge weight $c_{link}(u,v)$ is computed as a convex combination parameterized by weights $w_R$ (\texttt{centralized\_w\_r}) and $w_e$ (\texttt{centralized\_w\_e}):
\begin{equation}
    c_{link}(u,v) = w_R \cdot \hat{t}_{link}(u,v) + w_e \cdot \hat{e}_{link}(u,v)
\end{equation}

Concurrently, the routine queries all candidate nodes in \texttt{globals.edge\_servers} to capture residual energy $B_i$, processor queue occupancy $W_{cpu,i}$ (\texttt{W\_cpu\_simpy}), network queue occupancy $W_{net,i}$ (\texttt{W\_net\_simpy}), processor clock speed $C_{sen,i}$, CPU energy coefficient $\kappa_i$ (\texttt{e\_coeff}), and orbital sunset timestamp $t_{sunset,i}$.

Listing~\ref{lst:orchestrator_mapping} shows the executable implementation of the constellation mapping procedure.

\begin{adjustwidth}{-2cm}{-2cm}
\begin{lstlisting}[language=Python, caption={Constellation Topology and SEN State Mapping via Multi-Source Dijkstra.}, label={lst:orchestrator_mapping}]
    def _map_constellation(self):
        """
        Map optimal routing paths from each Access Point (AP) to all candidate 
        Satellite Edge Nodes (SENs) using Dijkstra's algorithm. 
        Link costs are computed as a weighted combination of Delay and Energy.
        """
        # Retrieve objective cost function weights from configuration settings
        w_e = self.config.get("centralized_w_e", 0.5)
        w_R = self.config.get("centralized_w_r", 0.5)
        p_trasm = self.config.get("Ptrasm", 1.0)

        # Standardize link evaluation using a 1 MB reference payload (in bytes)
        REF_DATA_BYTES = 1024 * 1024 

        network_state = {
            "routing_table": {}, # Format: {ap_name: {sen_name: {'total_cost': X, 'total_time': Y, 'total_energy': Z, 'path': [...]}}}
            "node_states": {}    # Format: {sen_name: {'energy_residual': X, 'W_cpu_simpy': Y, ...}}
        }

        # 1. Collect all topology nodes to facilitate network graph traversal
        all_nodes = globals.global_access_point + globals.edge_servers
        node_dict = {n.name: n for n in all_nodes}

        # 2. Multi-Source Dijkstra: Explore network topology starting from each AP
        for ap in globals.global_access_point:
            network_state["routing_table"][ap.name] = {}
            
            # Priority queue tuple structure:
            # (total_cost, total_time, total_energy, current_node_name, path_so_far)
            pq = [(0.0, 0.0, 0.0, ap.name, [ap.name])]
            
            # Track minimum discovered cost to reach each node from this AP
            min_costs = {ap.name: 0.0}

            while pq:
                current_cost, current_time, current_energy, current_node_name, path = heapq.heappop(pq)
                
                # Skip obsolete (sub-optimal) popped paths
                if current_cost > min_costs.get(current_node_name, float('inf')):
                    continue

                # If current node is a Satellite Edge Node (SEN), store its optimal routing path
                current_node_obj = node_dict[current_node_name]
                if current_node_obj in globals.edge_servers:
                    network_state["routing_table"][ap.name][current_node_name] = {
                        "total_cost": current_cost,
                        "total_time": current_time,
                        "total_energy": current_energy,
                        "path": path
                    }

                # Explore physical network neighbors of the current node
                for neighbor in current_node_obj.get_neighbors():

                    if neighbor.name not in node_dict:
                        continue

                    # Extract physical communication link metrics
                    latency = current_node_obj.get_latency(neighbor) or 0.0
                    bw_MBps = current_node_obj.get_bandwidth(neighbor) or 0.0
                    bw_Bps = bw_MBps * (1024**2)

                    # Link interrupted if available bandwidth is zero or negative
                    if bw_Bps <= 0:
                        continue

                    # Set estimated bounds for network normalization
                    MIN_BW_BPS = 100000 # Example: 100 KB/s
                    MAX_LATENCY = 0.1   # Example: 100 ms

                    # Calculate theoretical upper bounds for reference payload
                    MAX_LINK_TIME = MAX_LATENCY + (REF_DATA_BYTES / MIN_BW_BPS)
                    MAX_LINK_ENERGY = current_node_obj.compute_routing_energy(REF_DATA_BYTES, bw_Bps, p_trasm)
                    
                    # Compute latency and energy required for reference payload transmission
                    trans_time = REF_DATA_BYTES / bw_Bps
                    link_time = latency + trans_time
                    link_energy = current_node_obj.compute_routing_energy(REF_DATA_BYTES, bw_Bps, p_trasm)

                    # Min-Max Normalization
                    norm_time = link_time / MAX_LINK_TIME if MAX_LINK_TIME > 0 else 0.0
                    norm_energy = link_energy / MAX_LINK_ENERGY if MAX_LINK_ENERGY > 0 else 0.0

                    # Dimensionless combined cost function for the link
                    link_cost = (w_R * norm_time) + (w_e * norm_energy)

                    new_cost = current_cost + link_cost
                    new_time = current_time + link_time
                    new_energy = current_energy + link_energy

                    # Update shortest path if a lower-cost route is found
                    if new_cost < min_costs.get(neighbor.name, float('inf')):
                        min_costs[neighbor.name] = new_cost
                        heapq.heappush(pq, (new_cost, new_time, new_energy, neighbor.name, path + [neighbor.name]))

        # 3. Map health and state metrics of candidate Satellite Edge Nodes (SENs)
        for node in globals.edge_servers:
            try:
                w_cpu_simpy = node.W_cpu()
            except Exception:
                w_cpu_simpy = getattr(node, "W_cpu", lambda: 0.0)()

            try:
                w_net_simpy = node.W_net()
            except Exception:
                w_net_simpy = getattr(node, "W_net", lambda: 0.0)()

            # ------------------------------
            # Compute orbital sunset time
            raw_sunset = getattr(node, "orbitalSunset", None)
            if raw_sunset is not None:
                safe_sunset = float(raw_sunset)
            else:
                safe_sunset = 0.0
            # ------------------------------

            # Construct node state snapshot
            network_state["node_states"][node.name] = {
                "energy_residual": node.energy,
                "W_cpu_simpy": w_cpu_simpy,
                "W_net_simpy": w_net_simpy,      
                "C_sen": getattr(node, "C_sen", 1e9),
                "e_coeff": self.config.get("energy_coefficient", 5e-26),
                "sunset_time": safe_sunset
            }

        return network_state
\end{lstlisting}

\section{Centralized Integer Linear Programming Formulation}
\label{sec:mathematical_model}

Let $R$ be the set of tasks extracted in the active batch and $S$ the set of candidate Satellite Edge Nodes. 
The optimization problem defines two families of binary decision variables:
\begin{align}
    x_{r,i} &\in \{0, 1\}, \quad \forall r \in R, \, \forall i \in S \quad \text{(1 if task $r$ is allocated to satellite $i$; 0 otherwise)} \\
    y_r &\in \{0, 1\}, \quad \forall r \in R \quad \text{(1 if task $r$ is explicitly rejected; 0 otherwise)}
\end{align}

\subsection{Latency, Energy, and Orbital Eclipse Modeling}
For each candidate allocation $(r, i)$, the end-to-end processing delay $R_{r,i}$ evaluated by the solver accounts for multi-hop uplink ISL transmission across path $\vec{P}_{up}(AP_r, i)$ and local computing delay:
\begin{equation}
    R_{r,i} = \underbrace{\sum_{(u,v) \in \vec{P}_{up}} \left( W_{net,u} + \frac{S_{req}}{B_{u,v}} + \tau_{u,v} \right)}_{T_{up}(r,i)} + \left( W_{cpu,i} + d_{cpu,r} \right)
    \label{eq:total_latency}
\end{equation}

The cumulative fleet energy expenditure $\epsilon_{r,i}$ evaluates the network forwarding energy across all intermediate ISL nodes along $\vec{P}_{up}$ alongside local CPU execution:
\begin{equation}
    \epsilon_{r,i} = \sum_{(u,v) \in \vec{P}_{up}} P_{net} \frac{S_{req}}{B_{u,v}} + \kappa_i \cdot d_{cpu,r} \cdot C_{sen,i}^3
    \label{eq:total_energy}
\end{equation}

To avoid assigning tasks to satellites nearing orbital eclipse, the orchestrator defines an orbital sunset penalty $\Omega_i \in [0, 1]$:
\begin{equation}
    \Omega_i = \begin{cases}
        1.0 - \frac{t_{sunset,i}}{\max_{k \in S} (t_{sunset,k})}, & \text{if } \max_{k \in S} (t_{sunset,k}) > 0 \\
        0.0, & \text{otherwise}
    \end{cases}
\end{equation}
Satellites currently unreachable due to orbital eclipse ($t_{sunset,i} = 0$) receive the maximum penalty $\Omega_i = 1.0$.

\subsection{Multi-Objective Function and System Constraints}
Let $P_{drop} = 10^6$ represent a massive penalty scalar ensuring that task rejection is strictly penalized unless physical constraints are violated. 
The aggregated fleet latency ($Z_{time}$), energy ($Z_{energy}$), and eclipse penalty ($Z_{sunset}$) are defined as:
\begin{align}
    Z_{time} &= \sum_{r \in R} \sum_{i \in S} x_{r,i} R_{r,i} + \sum_{r \in R} y_r P_{drop} \\
    Z_{energy} &= \sum_{r \in R} \sum_{i \in S} x_{r,i} \epsilon_{r,i} + \sum_{r \in R} y_r P_{drop} \\
    Z_{sunset} &= \sum_{r \in R} \sum_{i \in S} x_{r,i} \Omega_i
\end{align}

Depending on the configuration parameter \texttt{centralized\_primary\_objective} (Time vs. Energy), the objective function $Z$ applies hierarchical weights ($\alpha = 10.0, \beta = 1.0, \gamma = 5.0$):
\begin{equation}
    \min Z = \begin{cases}
        \alpha Z_{time} + \beta Z_{energy} + \gamma Z_{sunset}, & \text{if primary strategy is Time} \\
        \alpha Z_{energy} + \beta Z_{time} + \gamma Z_{sunset}, & \text{if primary strategy is Energy}
    \end{cases}
    \label{eq:objective_function}
\end{equation}

The optimization space is constrained by four strict linear relations:
\begin{enumerate}
    \item \textbf{Decision Uniqueness:} Every task must be assigned to exactly one satellite or dropped:
    \begin{equation}
        \sum_{i \in S} x_{r,i} + y_r = 1, \quad \forall r \in R
    \end{equation}
    \item \textbf{Strict Service Processing Deadline:} Enforces that uplink forwarding and local execution do not exceed the deadline $D_r$:
    \begin{equation}
        x_{r,i} \cdot R_{r,i} \le D_r, \quad \forall r \in R, \, \forall i \in S
    \end{equation}
    \item \textbf{Distributed Fleet Energy Budget:} Enforces that the total energy allocated to satellite node $k$ (across all tasks where $k$ is an intermediate ISL forwarder or execution node) remains within its residual battery capacity $B_k$:
    \begin{equation}
        \sum_{r \in R} \sum_{i \in S} x_{r,i} \cdot \epsilon_{r,i,k} \le B_k, \quad \forall k \in S
    \end{equation}
    \item \textbf{Constellation Load Balancing (Anti-Congestion):} Prevents processor queue bottlenecks by bounding the maximum simultaneous task allocations per node:
    \begin{equation}
        \sum_{r \in R} x_{r,i} \le \left\lfloor \frac{|R|}{|S|} \right\rfloor + 5, \quad \forall i \in S
    \end{equation}
\end{enumerate}

\subsection{Solver Routine and Cascade Rejection Diagnostics}
The model is constructed in Python using \texttt{PuLP} and executed via the \texttt{HiGHS} solver engine. 
Upon resolution, if a task is rejected ($y_r = 1$), the orchestrator executes a cascade diagnostic evaluation across all reachable SENs to classify the primary drop reason:
\begin{itemize}
    \item \texttt{"No\_Route"}: No viable ISL path exists from $AP_r$ to any satellite.
    \item \texttt{"Deadline\_Violation"}: Predicted response time $R_{r,i}$ exceeds $D_r$.
    \item \texttt{"Sunset\_Violation"}: Response time exceeds available solar visibility horizon $t_{sunset,i}$.
    \item \texttt{"Energy\_Exhaustion"}: Residual battery $B_k$ is insufficient for multi-hop transmission or computing.
    \item \texttt{"Load\_Balancing\_Rejected"}: Satellite reached its maximum capacity threshold.
    \item \texttt{"Global\_ILP\_Conflict"}: Task rejected to preserve global objective optimality under shared fleet constraints.
\end{itemize}

Listing~\ref{lst:orchestrator_ilp} presents the complete \texttt{\_solve\_ilp} implementation.

\begin{adjustwidth}{-2cm}{-2cm}
\begin{lstlisting}[language=Python, caption={PuLP ILP Formulation, HiGHS Resolution, and Cascade Rejection Diagnostics.}, label={lst:orchestrator_ilp}]
    def _solve_ilp(self, network_state, tasks):
        """
        Open-Source Hierarchical PuLP Optimization Model
        """
        # Instantiate minimization optimization problem
        m = pulp.LpProblem("SECMotionModel_Centralized_ILP", pulp.LpMinimize)

        # Configuration parameters
        primary_obj = self.config.get("centralized_primary_objective", "time")
        
        # Fixed control payload for uplink request (2 KB)
        S_REQ_BYTES = 2048  
        p_net = self.config.get("Ptrasm", 1.0)
        
        R_set = tasks
        S_set = list(network_state["node_states"].keys())
        all_nodes = globals.global_access_point + globals.edge_servers
        node_dict = {n.name: n for n in all_nodes}

        # Decision variable definitions: x[r, i] in {0, 1}, y[r] in {0, 1}
        x = pulp.LpVariable.dicts("x", ((r, i) for r in range(len(R_set)) for i in S_set), cat='Binary')
        y = pulp.LpVariable.dicts("y", (r for r in range(len(R_set))), cat='Binary')

        # --- CONSTRAINT 1: Assignment or Drop Uniqueness ---
        for r_idx in range(len(R_set)):
            # Sum of satellite assignments plus rejection variable must equal 1
            m += pulp.lpSum(x[r_idx, i] for i in S_set) + y[r_idx] == 1, f"Assign_Or_Drop_{r_idx}"

        time_costs = {}
        energy_costs = {}
        
        node_energy_expressions = {k: [] for k in S_set}

        # 2. Parameter construction and physical constraints
        for r_idx, task in enumerate(R_set):
            task_data = task["data"]
            ap_origin = task["visible_aps"][0].name
            d_cpu = task_data.get('d_cpu', 0.0)
            deadline = task_data.get('deadline', 300.0)
            s_r_bytes = task_data.get('image_size', 0.0) * 1024 * 1024
            
            for i in S_set:
                route_info_up = network_state["routing_table"].get(ap_origin, {}).get(i)
                
                if not route_info_up:
                    m += x[r_idx, i] == 0, f"NoRoute_{r_idx}_{i}"
                    time_costs[r_idx, i] = 0
                    energy_costs[r_idx, i] = 0
                    continue

                path_up = route_info_up["path"]
                num_hops_up = len(path_up) - 1

                t_up = 0.0
                e_fwd_total = 0.0

                # --- UPLINK Latency and Energy Computation ---
                for h in range(num_hops_up):
                    node_curr = node_dict[path_up[h]]
                    node_next = node_dict[path_up[h+1]]
                    lat = node_curr.get_latency(node_next) or 0.0
                    
                    bw_raw = node_curr.get_bandwidth(node_next) or 0.0
                    b_isl = (bw_raw / 8.0) * (1024 ** 2) if bw_raw > 0 else 0.0
                    
                    if b_isl > 0:
                        Wn = network_state["node_states"].get(node_curr.name, {}).get("W_net_simpy", 0.0)
                        d_net_hop = S_REQ_BYTES / b_isl
                        t_up += Wn + d_net_hop + lat

                        if hasattr(node_curr, 'compute_routing_energy'):
                            e_hop_fwd = node_curr.compute_routing_energy(S_REQ_BYTES, b_isl, p_net)
                        else:
                            e_hop_fwd = p_net * (S_REQ_BYTES / b_isl)
                            
                        e_fwd_total += e_hop_fwd
                        
                        if node_curr.name in S_set:
                            node_energy_expressions[node_curr.name].append(x[r_idx, i] * e_hop_fwd)

                # --- LOCAL CPU EXECUTION (Latency and Energy) ---
                node_obj = node_dict[i]
                c_sen_i = network_state["node_states"][i]["C_sen"]
                e_coeff_i = network_state["node_states"][i]["e_coeff"]

                # Execution latency
                Wc = network_state["node_states"][i].get("W_cpu_simpy", 0.0)
                t_cpu_local = Wc + d_cpu

                # Execution energy
                if hasattr(node_obj, 'compute_execution_energy'):
                    e_cpu_local = node_obj.compute_execution_energy(d_cpu, c_sen_i, e=e_coeff_i)
                else:
                    e_cpu_local = d_cpu * e_coeff_i * (c_sen_i ** 3)
                    
                node_energy_expressions[i].append(x[r_idx, i] * e_cpu_local)

                # --- METRIC AGGREGATION AND DEADLINE CONSTRAINT ---
                time_costs[r_idx, i] = t_up + t_cpu_local
                energy_costs[r_idx, i] = e_fwd_total + e_cpu_local

                # Constraint 2: Strict Service Deadline Compliance
                R_ri_for_constraint = t_up + t_cpu_local
                m += x[r_idx, i] * R_ri_for_constraint <= deadline, f"Deadline_{r_idx}_{i}"

        # Constraint 3: Distributed Fleet Energy Budget Limit
        for k in S_set:
            budget_k = max(0.0, network_state["node_states"][k]["energy_residual"])
            if node_energy_expressions[k]:
                m += pulp.lpSum(node_energy_expressions[k]) <= budget_k, f"Energy_Limit_{k}"

        # --- Constraint 4: Anti-Congestion and Load Balancing ---
        num_satellites = len(S_set)
        fair_share = len(R_set) // num_satellites if num_satellites > 0 else len(R_set)
        MAX_TASKS_PER_NODE = fair_share + 5 
            
        for i in S_set:
            m += pulp.lpSum(x[r_idx, i] for r_idx in range(len(R_set))) <= MAX_TASKS_PER_NODE, f"Max_Capacity_{i}"
        
        # --- ORBITAL SUNSET PENALTY PREPARATION ---
        valid_sunsets = [network_state["node_states"][k].get("sunset_time", 0.0) for k in S_set]
        max_sunset = max(valid_sunsets + [1.0])
        
        sunset_penalties = {}
        for i in S_set:
            s_time = network_state["node_states"][i].get("sunset_time", 0.0)
            sunset_penalties[i] = 1.0 - (s_time / max_sunset) if max_sunset > 0 else 0.0

        # 3. Hierarchical Optimization Formulation
        PENALTY_VALUE = 1000000.0
        
        obj_time = pulp.lpSum(x[r_idx, i] * time_costs[r_idx, i] for r_idx in range(len(R_set)) for i in S_set) + \
                   pulp.lpSum(y[r_idx] * PENALTY_VALUE for r_idx in range(len(R_set)))
                   
        obj_energy = pulp.lpSum(x[r_idx, i] * energy_costs[r_idx, i] for r_idx in range(len(R_set)) for i in S_set) + \
                     pulp.lpSum(y[r_idx] * PENALTY_VALUE for r_idx in range(len(R_set)))

        obj_sunset = pulp.lpSum(x[r_idx, i] * sunset_penalties[i] for r_idx in range(len(R_set)) for i in S_set)

        WEIGHT_PRIMARY = 10.0
        WEIGHT_SECONDARY = 1.0
        WEIGHT_SUNSET = 5.0

        if primary_obj == "time":
            m += WEIGHT_PRIMARY * obj_time + WEIGHT_SECONDARY * obj_energy + WEIGHT_SUNSET * obj_sunset, "Total_Objective"
        else:
            m += WEIGHT_PRIMARY * obj_energy + WEIGHT_SECONDARY * obj_time + WEIGHT_SUNSET * obj_sunset, "Total_Objective"

        # 4. Problem Resolution via HiGHS Solver
        solver = pulp.getSolver('HiGHS', msg=False)
        m.solve(solver)
        
        status = pulp.LpStatus[m.status]
        
        assigned_energy_per_node = {i: 0.0 for i in S_set}
        assigned_tasks_per_node = {i: 0 for i in S_set}
        
        if status in ('Optimal', 'Suboptimal'):
            for r_idx in range(len(R_set)):
                if pulp.value(y[r_idx]) is not None and pulp.value(y[r_idx]) < 0.5:
                    for i in S_set:
                        if pulp.value(x[r_idx, i]) is not None and pulp.value(x[r_idx, i]) > 0.5:
                            assigned_energy_per_node[i] += energy_costs.get((r_idx, i), 0.0)
                            assigned_tasks_per_node[i] += 1

        # Decision Matrix Parsing and Cascade Rejection Diagnostics
        assignments = []
        if status in ('Optimal', 'Suboptimal'):
            for r_idx, task in enumerate(R_set):
                if pulp.value(y[r_idx]) and pulp.value(y[r_idx]) > 0.5:
                    ap_origin = task["visible_aps"][0].name
                    deadline = task["data"].get('deadline', 300.0)
                    specific_reason = "Unknown"
                    
                    reachable_sens = [i for i in S_set if network_state["routing_table"].get(ap_origin, {}).get(i)]
                    
                    if not reachable_sens:
                        specific_reason = "No_Route"
                    else:
                        reasons_for_rejection = []
                        for i in reachable_sens:
                            R_ri = time_costs.get((r_idx, i), 0)
                            E_ri = energy_costs.get((r_idx, i), 0)
                            s_time_i = network_state["node_states"][i].get("sunset_time", 0)
                            actual_energy_left = network_state["node_states"][i]["energy_residual"] - assigned_energy_per_node.get(i, 0)
                            
                            if R_ri == 0 or R_ri > deadline:
                                reasons_for_rejection.append("Deadline_Violation")
                            elif R_ri > s_time_i:
                                reasons_for_rejection.append("Sunset_Violation")
                            elif actual_energy_left < E_ri:
                                reasons_for_rejection.append("Energy_Exhaustion")
                            elif assigned_tasks_per_node.get(i, 0) >= MAX_TASKS_PER_NODE:
                                reasons_for_rejection.append("Load_Balancing_Rejected")
                            else:
                                reasons_for_rejection.append("Global_ILP_Conflict")
                        
                        if reasons_for_rejection:
                            specific_reason = max(set(reasons_for_rejection), key=reasons_for_rejection.count)
                        else:
                            specific_reason = "Unknown"

                    print(f"[{self.env.now:.3f}] Orchestrator: Task {task['task_id']} rejected by ILP. Cause: {specific_reason}")

                    assignments.append({
                        "task_id": task["task_id"], "data": task["data"],
                        "assigned_sen": None, "routing_path_up": [], "routing_path_down": [],
                        "status": f"Scartato_{specific_reason}"
                    })
                    continue

                assigned_node = None
                for i in S_set:
                    if pulp.value(x[r_idx, i]) and pulp.value(x[r_idx, i]) > 0.5:
                        assigned_node = i
                        break
                
                if assigned_node:
                    ap_origin = task["visible_aps"][0].name
                    path_up = network_state["routing_table"][ap_origin][assigned_node]["path"]
                    path_down = [assigned_node, ap_origin]

                    assignments.append({
                        "task_id": task["task_id"], "data": task["data"],
                        "assigned_sen": assigned_node, "routing_path_up": path_up,
                        "routing_path_down": path_down, "status": "Assigned"
                    })
        else:
            print(f"[{self.env.now:.2f}] [ILP Centralized] Batch Infeasible. Status: {status}")
            for task in R_set:
                assignments.append({
                    "task_id": task["task_id"], "data": task["data"],
                    "assigned_sen": None, "routing_path_up": [], "routing_path_down": [],
                    "status": "Infeasible"
                })

        return assignments
\end{lstlisting}
\end{adjustwidth}

\section{Task Execution and Resilient Hybrid Routing}
\label{sec:task_execution_routing}

Once the ILP optimizer produces the assignment decision matrix, the orchestrator invokes \texttt{\_dispatch\_tasks} to spawn independent \texttt{\_route\_and\_execute\_task} processes for each accepted request. 
Due to high orbital velocities in LEO constellations, planned ISL links may experience unexpected line-of-sight obstruction or degradation mid-flight. 
To guarantee fault tolerance, packet routing employs a dynamic hybrid routing protocol:
\begin{itemize}
    \item \textbf{Nominal Planned Routing (Phase A):} Data packets strictly follow the shortest multi-hop ISL trajectory $\vec{P}_{up}$ pre-computed during constellation mapping.
    \item \textbf{Emergency Geographic Greedy Fallback (Phase B):} If an intermediate link fails ($B_{u,v} \le 0$), the current node autonomously triggers greedy geographic recovery. The node inspects all available physical neighbors, calculates their Euclidean distance to the destination satellite via \texttt{get\_pos\_proximity}, and forwards the packet to the closest non-visited node. Visited sets (\texttt{routing\_task.visited}) prevent forwarding loops.
\end{itemize}

Upon packet arrival at the destination Satellite Edge Node, the transmission duration and hop count are logged in \texttt{globals.gbl\_generated\_tasks\_data}, and the process yields to the discrete-event CPU simulator (\texttt{ILP\_simulation.TaskAssignment\_ILP}). 
Finally, task status and timing metrics are synchronized in the global dataset.

Listing~\ref{lst:orchestrator_routing} shows the hybrid routing and execution routine.

\begin{adjustwidth}{-2cm}{-2cm}
\begin{lstlisting}[language=Python, caption={Task Execution and Dynamic Hybrid Routing Procedure.}, label={lst:orchestrator_routing}]
    def _route_and_execute_task(self, assignment, all_nodes, dispatch_time):
            task_id = assignment["task_id"]
            data = assignment["data"]
            sen_name = assignment["assigned_sen"]
            sen_obj = all_nodes.get(sen_name)
            path_up = assignment.get("routing_path_up", [])

            ap_origin = path_up[0] if path_up else globals.global_access_point[0].name

            # --- 1. TRANSIENT ROUTING TASK CREATION ---
            routing_task = Task(
                task_id=task_id,
                current_node=ap_origin,
                dest_node=sen_name,
                routingInitTime=dispatch_time,
                task_type=data["type"],
                image_size=data["image_size"]
            )
            routing_task.weight = data["image_size"]
            routing_task.visited.add(ap_origin) 
            
            start_node = all_nodes.get(ap_origin)
            if start_node and routing_task not in start_node.tasks:
                start_node.tasks.append(routing_task)

            # --- 2. DYNAMIC NAVIGATION LOOP (Hybrid Routing: ILP -> GREEDY) ---
            current_node_name = ap_origin
            target_dest_name = sen_name
            path_index = 0
            is_greedy = False 
        
            while current_node_name != target_dest_name:
                current_node_obj = all_nodes.get(current_node_name)
                
                if not is_greedy:
                    # ==========================================
                    # PHASE A: PLANNED ROUTE NAVIGATION (ILP)
                    # ==========================================
                    next_planned = path_up[path_index + 1] if path_index < len(path_up) - 1 else None
                    next_planned_obj = all_nodes.get(next_planned) if next_planned else None

                    if next_planned_obj and current_node_obj.get_bandwidth(next_planned_obj) > 0:
                        # Active link: follow Orchestrator plan
                        yield self.env.process(
                            utils.sendTask(self.env, routing_task, current_node_obj, next_planned_obj, "ILP_Centralized")
                        )
                        path_index += 1
                        routing_task.visited.add(next_planned)
                    else:
                        # BROKEN LINK: Trigger greedy recovery fallback!
                        print(f"[{self.env.now:.3f}] Orchestrator: Interrupted link at node {current_node_name} (Task {task_id}). Activating GREEDY Fallback!")
                        is_greedy = True
                        
                if is_greedy:
                    # ==========================================
                    # PHASE B: EMERGENCY RECOVERY NAVIGATION (GREEDY)
                    # ==========================================
                    target_dest_obj = all_nodes.get(target_dest_name)
                    dest_pos = target_dest_obj.getPositionVector(globals.ist_in_conf)
                    ranker_neighbors = []
                    neighbors_list = getattr(current_node_obj, 'neighbors', current_node_obj.get_neighbors())

                    for server in neighbors_list:
                        if current_node_obj.get_bandwidth(server) > 0:
                            neighbor_distance = get_pos_proximity(dest_pos, server.getPositionVector(globals.ist_in_conf))
                            is_ap = getattr(server, 'is_acc_point', False)
                            ranker_neighbors.append((server, neighbor_distance, is_ap))

                    ranker_neighbors.sort(key=lambda x: (not x[2], x[1]))

                    best_server = None
                    for neighbor_tuple in ranker_neighbors:
                        # Prevent loops between adjacent satellites
                        if neighbor_tuple[0].name not in routing_task.visited:
                            best_server = neighbor_tuple[0]
                            break

                    if best_server:
                        yield self.env.process(
                            utils.sendTask(self.env, routing_task, current_node_obj, best_server, 'GREEDY_FALLBACK')
                        )
                        routing_task.visited.add(best_server.name)
                    else:
                        print(f"[{self.env.now:.3f}] Orchestrator: GREEDY Fallback failed (dead-end) at node {current_node_name}. Task {task_id} dropped.")
                        routing_task.routingEndTime = self.env.now
                        routing_task.label = "DROPPED_GREEDY_DEADEND"
                        globals.gbl_tasks.append(routing_task)
                        return


                if getattr(routing_task, 'label', '') == 'TTL_EXPIRED':
                    print(f"[{self.env.now:.3f}] Orchestrator: Task {task_id} dropped due to expired TTL during routing.")
                    globals.gbl_tasks.append(routing_task)
                    return

                current_node_name = routing_task.current_node

            # --- 3. FINAL DESTINATION ARRIVAL ---
            transfer_time_up = self.env.now - data.get("arrival_time", dispatch_time)
            final_hops = routing_task.hop
            init_time = routing_task.routingInitTime
            end_time = self.env.now
            algos = routing_task.algorithms_used

            print(f"[{self.env.now:.3f}] Orchestrator: Task {task_id} arrived at {sen_name} in {transfer_time_up:.3f}s (Hops: {final_hops})")

            # --- 4. METRICS & DATASET LOGGING ---
            globals.initial_server_counter[sen_name] = globals.initial_server_counter.get(sen_name, 0) + 1
            globals.gbl_task_hops[str(task_id)] = final_hops
            globals.gbl_task_final_hops[str(task_id)] = final_hops
            globals.gbl_generated_tasks_data.append({
                "task_id": task_id, "arrival_time": data.get("arrival_time", dispatch_time), "type": data["type"],
                "ram": data.get("required_ram", 0), "disk": data.get("required_disk", 0),
                "image_size": data["image_size"], "exec_time": data["d_cpu"],
                "transfer_time": transfer_time_up, "performed_transfers": final_hops,
                "final_hops": final_hops, "execution_server": sen_name
            })

            # --- 5. DISCRETE-EVENT CPU SIMULATION EXECUTION ---
            yield self.env.process(
                ILP_simulation.TaskAssignment_ILP(
                    env=self.env, selected_server=sen_obj, task_id=task_id, image_size=data["image_size"],
                    arrival_time_system=data.get("arrival_time", dispatch_time), num_hops=final_hops, 
                    transfer_time=transfer_time_up, task_type=data["type"], d_cpu=data["d_cpu"], D_r=data["deadline"],
                    net_bw_override_Bps=None, result_sink={}, allow_retry=False,              
                    routing_already_charged=True, routing_energy_from=None, transfer_already_simulated=True
                )
            )

            # --- 6. POST-EXECUTION METRICS SYNCHRONIZATION ---
            final_task = next((t for t in globals.gbl_tasks if t.id == task_id), None)
            if final_task:
                final_task.hop = final_hops
                final_task.routingInitTime = init_time
                final_task.routingEndTime = end_time
                final_task.algorithms_used = algos
            else:
                routing_task.routingEndTime = end_time
                routing_task.label = "REJECTED_POST_ROUTING"
                globals.gbl_tasks.append(routing_task)
\end{lstlisting}

\section{Computational Complexity and Scalability Analysis}
\label{sec:complexity_analysis}

To understand the computational trade-offs of centralized ILP orchestration compared to distributed heuristics, we formally analyze the algorithmic time and space complexity across all pipeline stages.

\subsection{Topology Mapping Complexity}
The constellation mapping routine executes Dijkstra's algorithm from each active Access Point $|AP|$ across the constellation graph $G = (V, E)$, where $V = AP_{global} \cup S$ and $E$ is the set of active ISL and ground links. 
Using a binary min-heap priority queue, the asymptotic time complexity is:
\begin{equation}
    \mathcal{O}\left( |AP| \cdot \left( |E| + |V| \log |V| \right) \right)
\end{equation}
Because satellite node degree in regular grid LEO constellations (e.g., Walker delta) is bounded by physical ISL transceivers ($|E| \le 4 |S|$), the mapping stage scales linearly with constellation size $|S|$.

\subsection{ILP Formulation and Solver Complexity}
For a batch containing $|R|$ requests and $|S|$ candidate Satellite Edge Nodes:
\begin{itemize}
    \item \textbf{Decision Variable Space:} The model instantiates $|R| \cdot |S|$ binary assignment variables $x_{r,i}$ and $|R|$ rejection variables $y_r$, yielding a total binary dimension of $\mathcal{O}(|R| \cdot |S|)$.
    \item \textbf{Constraint Space:} The formulation constructs $|R|$ uniqueness constraints, $|R| \cdot |S|$ deadline constraints, $|S|$ fleet battery constraints, and $|S|$ load-balancing constraints, yielding an exact row complexity of:
    \begin{equation}
        \mathcal{O}\left( |R| \cdot |S| + |R| + 2|S| \right)
    \end{equation}
\end{itemize}
While solving general 0-1 Integer Linear Programs is NP-hard, with a worst-case time complexity of $\mathcal{O}(2^{|R| \cdot |S|})$, the branch-and-cut algorithm in \texttt{HiGHS} solves the linear relaxation at each search node in polynomial time. 
The dynamic batching threshold $BS \le 20$ guarantees that the active problem space remains strictly bounded, maintaining mean solving times below $10~\text{ms}$ in practical regional operations.
\subsection{Hybrid Routing Complexity}
Under nominal operation, planned packet forwarding requires $\mathcal{O}(h_{up})$ pointer lookups along pre-computed paths. 
In the event of link failure, the greedy fallback evaluates the spatial distance of adjacent neighbors ($k$) in $\mathcal{O}(k \log k)$ time per hop. 
The visited set lookup operates in $\mathcal{O}(1)$ average time using hash tables, guaranteeing that emergency routing overhead remains negligible relative to optical ISL propagation delays.
